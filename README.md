# Cuarto de la bebé

Planificador a escala (275 × 350 cm) para probar dónde colocar la cuna y el resto de muebles.

## Cómo usarlo

- **En el móvil o en cualquier navegador:** abre la web de GitHub Pages del repositorio.
- **En tu ordenador:** descarga `index.html` y ábrelo con doble clic. No hace falta instalar nada.

Arrastra los muebles para moverlos. En el móvil, la barra de abajo permite mover de 1 en 1 cm, girar, copiar y quitar. En el ordenador: flechas para mover 1 cm (Mayús 10 cm), `R` para girar, `Supr` para quitar.

Las distribuciones se guardan en el navegador donde las hagas (no se sincronizan entre dispositivos).
